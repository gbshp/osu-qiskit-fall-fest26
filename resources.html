Learning Qiskit

    Make a free account before the kickoff — it's what you'll use to run circuits on real quantum hardware during the hackathon.

  • IBM Quantum Learning

    Free structured courses, from "what is a qubit" through error correction. The basics of quantum information course is the best single starting point.

  • Qiskit

    The open-source Python SDK we build with all week. This page covers what it is and how to install it locally if you'd rather not work in the browser.

  • Qiskit Documentation

    API reference and how-to guides. Worth bookmarking before the hackathon starts.

  • Qiskit Fall Fest 2026

    IBM's announcement of this year's global program. The 2026 theme marks ten years since IBM put a quantum computer on the cloud for anyone to use.
